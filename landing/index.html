for people who stash and forget

Your old stashes, finally searchable by what they actually do.

git stash list gives you stash@{7}: WIP on main: 8f2a1bc quick fix. Three weeks later that tells you nothing. stowwit reads the diff, asks an AI what it does, and lets you search stashes by intent, across every repo you've stashed in, instead of re-opening each one to remember.

View on GitHub Read the install guide

A real stash, summarized locally by Ollama. No cloud call, nothing leaving your machine.

The opacity problem

Stashes are meant to be short-lived, but in practice they pile up: across days, across repos, across "I'll get back to this." By the time you do, the label is useless and the only way to know what's inside is to open it and read the raw diff yourself, one stash at a time.

beforestash@{4}: WIP on main: 3f2a1bc quick fix
afterfix: auth redirect loop after logout

Built local-first, on purpose

Point it at Ollama and your diffs never leave your machine. That is the point for anyone whose stashes touch code that can't be pasted into a cloud tool. Swap to Gemini or Claude with one environment variable if you'd rather trade privacy for a stronger model.

One engine, three surfaces

The same local engine powers a CLI, a VS Code extension, and a desktop app. Index once, browse however you already work.

Bring your own provider

Ollama, Gemini, or Claude, chosen with a single environment variable. Nothing hardcoded.

Open source, MIT licensed

Read the code, run it yourself, fork it. Nothing about how it works is hidden.

Get running in a few minutes

01

Clone and install

git clone https://github.com/yazhnar/stowwit.git
cd stowwit
npm install
02

Install Ollama for local, private summaries

ollama pull qwen2.5-coder

Or skip this and use Gemini/Claude instead. The README covers both.

03

Point stowwit at a repo

cp packages/core/.env.example packages/core/.env
# set REPO_PATH to the repo you want indexed
04

Run it

npm run dev

Open localhost:5173, hit "Sync stashes," and start searching.
